# 講義ノートAI 仕様書 (SPEC.md)

## 1. アプリ概要
- **目的**: 講義や自習の音声データから文字起こし・要約・要点を自動生成し、学習ノート作成を効率化する。
- **ターゲット**: スマホ/PCブラウザから利用する学生・社会人学習者。
- **構成**: HTML/CSS/JS による 1 ページ構成（Single Page App）。

## 2. 画面構成・コンポーネント
1. **ヘッダー**: タイトル、APIキー設定モーダル起動ボタン（接続ステータスインジケーター付き）。
2. **APIキー設定モーダル**: キー入力フィールド、localStorage保存・削除ボタン。
3. **講義情報入力欄**: 講義タイトルの入力（任意）。
4. **音声入力セクション**: ファイル選択（`audio/*`）、音声プレビュー用 `<audio>` プレイヤー。
5. **実行ボタン & エラー表示領域**: 実行制御、処理中メッセージ提示、エラー発生時の赤枠アラート。
6. **結果表示エリア**:
   - **タブ1 (要約 & 要点)**: 3行要約表示枠、主要ポイント（箇条書き）表示枠、一括コピーボタン。
   - **タブ2 (全文文字起こし)**: 全文テキスト表示枠（スクロール対応）、コピーボタン。

## 3. ユーザー導線（UX Flow）
1. 起動時に `localStorage`（キー名: `gemini_api_key`）から APIキー を取得。未設定の場合はヘッダーに赤色ステータスを表示。
2. 音声ファイル（MP3/M4A/WAV等）を選択し、プレビューで再生確認。
3. 実行ボタン押下で `FileReader` による Base64 エンコード処理 ➔ Gemini API へ POST リクエスト送信。
4. 処理中はボタンを非活性化（`disabled`）し「⏳ 音声を解析中...」の表示へ切り替え。
5. レスポンス受領後、指定セパレーター（`---3行要約---` 等）でレスポンスをパースし各要素へ描画。
6. コピーボタンでクリップボードへ結果を出力。

## 4. エラーハンドリング要件
- **APIキー未設定時**: 警告アラートを表示し、設定モーダルを自動起動。
- **音声ファイル未選択時**: 「音声ファイルを選択してください」アラートを表示。
- **API通信失敗（HTTP 4xx/5xx 等）**: APIから返却されたエラーメッセージまたはステータスコードを画面下部の赤枠アラート枠に表示。
