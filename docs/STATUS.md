# 開発ステータス & 進捗ログ (STATUS.md)

## 現在地
- **ステータス**: MVP（最小可動プロダクト）完成 ＆ 動作検証完了
- **公開状況**: 静的Webサーバー / GitHub Pages 公開準備完了

## 実施した作業
1. **フロントエンド実装**:
   - Vanilla JS + Tailwind CSS による Single Page Application (SPA) 構築。
   - タブ切り替えUI（要約・要点 / 全文文字起こし）の実装。
2. **APIキー保持ロジック**:
   - `localStorage` を利用した安全なクライアントサイド保存の実装。
3. **音声データ変換ロジック**:
   - `FileReader` を使用し、選択された音声ファイルを Base64 データ化する非同期処理（`fileToBase64`）の実装。
4. **Gemini API 連携**:
   - `gemini-3.5-flash-lite` エンドポイントへの REST API リクエスト構築。
   - プロンプト指示による構造化テキスト出力と、セパレーターに基づいたパースロジックの実装。

## 詰まり・課題の記録と解決
- **Base64形式のプレフィックス問題**:
  - `FileReader.readAsDataURL()` で取得できる文字列には `data:audio/mp3;base64,` が含まれるため、Gemini API の `inlineData.data` に渡す前に `split(',')[1]` で除去する処理を追加して解決。
- **出力フォーマットのパース安定化**:
  - AIからのレスポンスを確実に画面パーツに分割できるよう、明確なセパレーター（`---3行要約---`、`---主要ポイント---`、`---全文文字起こし---`）をプロンプト側で厳格に指定。
